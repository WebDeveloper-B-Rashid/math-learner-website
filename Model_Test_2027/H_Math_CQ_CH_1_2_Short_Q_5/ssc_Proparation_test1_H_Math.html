যে কোনো বিভাগ থেকে ১টি করে মোট ২টি প্রশ্নের উত্তর দাও।
ক-বিভাগ: সেট ও ফাংশন
১. f(x) = (2x + 3) / (x - 2) একটি ফাংশন; যেখানে x ≠ 2 .
ক. f(-2) এর মান নির্ণয় কর। [২]
খ. f(x) দ্বারা বর্ণিত ফাংশনটি এক-এক কিনা তা নির্ণয় কর। [৪]
গ. f⁻¹(x) = 3x হলে, x এর সম্ভাব্য মান নির্ণয় কর। [৪]
খ-বিভাগ: বীজগাণিতিক রাশি
২. F(x, y, z) = x⁻³ + y⁻³ + z⁻³ - 3x⁻¹y⁻¹z⁻¹ এবং a = y + z - x, b = z + x - y, c = x + y - z .
ক. দেখাও যে, (a/b) + (b/c) + (c/a) রাশিটি a, b, c চলকের চক্রক্রমিক রাশি। [২]
খ. F(x, y, z) = 0 হলে, প্রমাণ কর যে, xy + yz + zx = 0 এবং x = y = z . [৪]
গ. প্রমাণ কর যে, a³ + b³ + c³ - 3abc = 4(x³ + y³ + z³ - 3xyz) . [৪]
Answer 2 questions in total, selecting one from each group.
Group A: Set and Function
1. f(x) = (2x + 3) / (x - 2) is a function; where x ≠ 2 .
a. Find the value of f(-2). [2]
b. Determine whether the function described by f(x) is a one-one function. [4]
c. If f⁻¹(x) = 3x, find the possible values of x. [4]
Group B: Algebraic Expression
2. F(x, y, z) = x⁻³ + y⁻³ + z⁻³ - 3x⁻¹y⁻¹z⁻¹ and a = y + z - x, b = z + x - y, c = x + y - z .
a. Show that the expression (a/b) + (b/c) + (c/a) is a cyclic expression of the variables a, b, c. [2]
b. If F(x, y, z) = 0, prove that xy + yz + zx = 0 and x = y = z . [4]
c. Prove that a³ + b³ + c³ - 3abc = 4(x³ + y³ + z³ - 3xyz) . [4]
