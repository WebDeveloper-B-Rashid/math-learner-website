১. \(A = \{a, b, c\}\) হলে \(P(A)\) এর প্রকৃত উপসেট সংখ্যা কত? 1. If \(A = \{a, b, c\}\), what is the number of proper subsets of \(P(A)\)?
Solution: উপাদান সংখ্যা \(n = 3\)। মোট উপসেট \(2^3 = 8\)। প্রকৃত উপসেট সংখ্যা = \(2^n - 1 = 8 - 1 = 7\)। Number of elements \(n = 3\). Total subsets \(2^3 = 8\). Proper subsets = \(2^n - 1 = 8 - 1 = 7\).
২. \(f(x) = \sqrt{x-2}\) ফাংশনটির ডোমেন কোনটি? 2. What is the domain of the function \(f(x) = \sqrt{x-2}\)?
Solution: বর্গমূলের ভেতরের মান অঋণাত্মক হতে হবে। অর্থাৎ, \(x - 2 \ge 0 \implies x \ge 2\)। The value inside the square root must be non-negative. So, \(x - 2 \ge 0 \implies x \ge 2\).
৩. \(f(x) = 2x + 1\) হলে \(f^{-1}(5)\) এর মান কত? 3. If \(f(x) = 2x + 1\), what is the value of \(f^{-1}(5)\)?
Solution: ধরি, \(f(x) = 5 \implies 2x + 1 = 5 \implies 2x = 4 \implies x = 2\)। Let \(f(x) = 5 \implies 2x + 1 = 5 \implies 2x = 4 \implies x = 2\).
৪. ডি মরগানের সূত্রানুসারে \((A \cup B)'\) এর সমান কোনটি? 4. According to De Morgan's Law, which of the following is equal to \((A \cup B)'\)?
Solution: ডি মরগানের সূত্র: \((A \cup B)' = A' \cap B'\)। De Morgan's Law states: \((A \cup B)' = A' \cap B'\).
৫. \(A = \{x \in \mathbb{N} : x < 5\}\) এবং \(B = \{x \in \mathbb{N} : x\) জোড় সংখ্যা\(\}\) হলে \(A \cap B\) কত? 5. If \(A = \{x \in \mathbb{N} : x < 5\}\) and \(B = \{x \in \mathbb{N} : x \text{ is an even number}\}\), what is \(A \cap B\)?
Solution: \(A = \{1, 2, 3, 4\}\) এবং \(B = \{2, 4, 6, 8, \dots\}\)। সুতরাং, \(A \cap B = \{2, 4\}\)। \(A = \{1, 2, 3, 4\}\) and \(B = \{2, 4, 6, 8, \dots\}\). Therefore, \(A \cap B = \{2, 4\}\).
৬. যদি \(n(A) = 4\) এবং \(n(B) = 5\) হয় এবং \(A \cap B = \emptyset\), তবে \(n(A \cup B)\) কত? 6. If \(n(A) = 4\) and \(n(B) = 5\), and \(A \cap B = \emptyset\), what is \(n(A \cup B)\)?
Solution: \(n(A \cup B) = n(A) + n(B) - n(A \cap B) = 4 + 5 - 0 = 9\)। \(n(A \cup B) = n(A) + n(B) - n(A \cap B) = 4 + 5 - 0 = 9\).
৭. \(f(x) = \frac{x}{x-1}\) ফাংশনটির রেঞ্জ কোনটি? 7. What is the range of the function \(f(x) = \frac{x}{x-1}\)?
Solution: ধরি \(y = \frac{x}{x-1} \implies yx - y = x \implies x(y - 1) = y \implies x = \frac{y}{y-1}\)। এখানে \(y \neq 1\)। রেঞ্জ \(\mathbb{R} \setminus \{1\}\)। Let \(y = \frac{x}{x-1} \implies yx - y = x \implies x(y - 1) = y \implies x = \frac{y}{y-1}\). Here \(y \neq 1\). Range is \(\mathbb{R} \setminus \{1\}\).
৮. \(S = \{(1,2), (2,3), (3,4)\}\) অন্বয়টির ডোমেন কোনটি? 8. What is the domain of the relation \(S = \{(1,2), (2,3), (3,4)\}\)?
Solution: ডোমেন হলো ক্রোমজোড়গুলোর প্রথম উপাদানসমূহের সেট। ডোম \(S = \{1, 2, 3\}\)। The domain is the set of the first elements of the ordered pairs. Dom \(S = \{1, 2, 3\}\).
৯. একটি সেটের উপাদান সংখ্যা \(n\) হলে, এর উপসেট সংখ্যা কত? 9. If a set has \(n\) elements, what is the total number of its subsets?
Solution: সূত্রের সাহায্যে আমরা জানি, \(n\) উপাদান বিশিষ্ট সেটের উপসেট সংখ্যা \(2^n\)। By formula, a set with \(n\) elements has \(2^n\) subsets.
১০. \(f(x) = x^2\) ফাংশনটি \(\mathbb{R} \to \mathbb{R}\) এ কেমন ফাংশন? 10. What type of function is \(f(x) = x^2\) from \(\mathbb{R} \to \mathbb{R}\)?
Solution: যেহেতু \(f(2) = 4\) এবং \(f(-2) = 4\), ভিন্ন ইনপুটের একই আউটপুট। তাই এটি এক-এক নয়। Since \(f(2) = 4\) and \(f(-2) = 4\), different inputs give the same output. Thus, it is not one-one.
