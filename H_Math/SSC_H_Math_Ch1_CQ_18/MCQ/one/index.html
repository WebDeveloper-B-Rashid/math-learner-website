১. $A = \{x \in \mathbb{N} : x^2 < 17\}$ হলে, $A$ সেটের প্রকৃত উপসেট সংখ্যা কত? 1. If $A = \{x \in \mathbb{N} : x^2 < 17\}$, what is the number of proper subsets of set A?
Solution:
যেহেতু $x \in \mathbb{N}$ এবং $x^2 < 17$, তাই $x$ এর মান হতে পারে $1, 2, 3, 4$।
সুতরাং, $A = \{1, 2, 3, 4\}$। উপাদান সংখ্যা $n = 4$।
প্রকৃত উপসেট সংখ্যা $= 2^n - 1 = 2^4 - 1 = 16 - 1 = 15$। Since $x \in \mathbb{N}$ and $x^2 < 17$, $x$ can be $1, 2, 3, 4$.
Thus, $A = \{1, 2, 3, 4\}$. Number of elements $n = 4$.
Proper subsets $= 2^n - 1 = 2^4 - 1 = 16 - 1 = 15$.
২. $f(x) = \frac{x-1}{x+1}$ ফাংশনটির ডোমেন কোনটি? 2. What is the domain of the function $f(x) = \frac{x-1}{x+1}$?
Solution:
ভগ্নাংশের হর শূন্য হতে পারবে না। অর্থাৎ, $x + 1 \neq 0 \implies x \neq -1$।
ডোমেন $= \mathbb{R} \setminus \{-1\}$। The denominator cannot be zero. So, $x + 1 \neq 0 \implies x \neq -1$.
Domain $= \mathbb{R} \setminus \{-1\}$.
৩. $f(x) = \sqrt{x-3}$ ফাংশনটির ডোমেন কত? 3. What is the domain of the function $f(x) = \sqrt{x-3}$?
Solution:
বর্গমূলের ভেতরের মান অঋণাত্মক হতে হবে। $x - 3 \ge 0 \implies x \ge 3$।
ব্যবধি আকারে: $[3, \infty)$। The value inside the square root must be non-negative. $x - 3 \ge 0 \implies x \ge 3$.
In interval notation: $[3, \infty)$.
৪. $n(A) = 3, n(B) = 4$ এবং $n(A \cap B) = 1$ হলে $n(A \cup B) = ?$ 4. If $n(A) = 3, n(B) = 4$, and $n(A \cap B) = 1$, then $n(A \cup B) = ?$
Solution:
সূত্র: $n(A \cup B) = n(A) + n(B) - n(A \cap B)$
$= 3 + 4 - 1 = 6$। Formula: $n(A \cup B) = n(A) + n(B) - n(A \cap B)$
$= 3 + 4 - 1 = 6$.
৫. $f(x) = 2x+3$ হলে, $f^{-1}(x)$ কোনটি? 5. If $f(x) = 2x+3$, which one is $f^{-1}(x)$?
Solution:
ধরি, $y = 2x + 3 \implies 2x = y - 3 \implies x = \frac{y-3}{2}$।
অতএব, $f^{-1}(x) = \frac{x-3}{2}$। Let $y = 2x + 3 \implies 2x = y - 3 \implies x = \frac{y-3}{2}$.
Therefore, $f^{-1}(x) = \frac{x-3}{2}$.
৬. $A$ এবং $B$ নিশ্ছেদ সেট হলে, $n(A \cap B)$ এর মান কত? 6. If $A$ and $B$ are disjoint sets, what is the value of $n(A \cap B)$?
Solution:
নিশ্ছেদ সেটের ক্ষেত্রে $A \cap B = \emptyset$ (ফাঁকা সেট)।
যেহেতু এখানে উপাদানের সংখ্যা ($n$) জানতে চাওয়া হয়েছে, তাই উত্তর হবে $0$। For disjoint sets, $A \cap B = \emptyset$ (empty set).
Since the number of elements ($n$) is asked, the answer is $0$.
৭. $S = \{(1,2), (2,3), (3,4)\}$ অন্বয়টির রেঞ্জ কোনটি? 7. What is the range of the relation $S = \{(1,2), (2,3), (3,4)\}$?
Solution:
অন্বয়ের রেঞ্জ হলো ক্রোমজোড়গুলোর দ্বিতীয় উপাদানসমূহের সেট।
দ্বিতীয় উপাদানগুলো হলো: $2, 3, 4$। রেঞ্জ = $\{2, 3, 4\}$। The range of a relation is the set of the second elements of the ordered pairs.
The second elements are $2, 3, 4$. Range = $\{2, 3, 4\}$.
৮. ডি মরগানের সূত্রানুসারে $(A \cap B)'$ সমান কোনটি? 8. According to De Morgan's Laws, what is $(A \cap B)'$ equal to?
Solution:
ডি মরগানের সূত্র: $(A \cap B)' = A' \cup B'$ এবং $(A \cup B)' = A' \cap B'$। De Morgan's Laws: $(A \cap B)' = A' \cup B'$ and $(A \cup B)' = A' \cap B'$.
৯. $f(x) = x^2 - 4x + 3$ হলে $f(2)$ এর মান কত? 9. If $f(x) = x^2 - 4x + 3$, what is the value of $f(2)$?
Solution:
$f(2) = (2)^2 - 4(2) + 3 = 4 - 8 + 3 = -1$। $f(2) = (2)^2 - 4(2) + 3 = 4 - 8 + 3 = -1$.
১০. $A \setminus B$ কে সেট গঠন পদ্ধতিতে কীভাবে লেখা যায়? 10. How is $A \setminus B$ expressed in set-builder notation?
Solution:
$A \setminus B$ মানে হলো সেইসব উপাদান যা $A$ তে আছে কিন্তু $B$ তে নেই।
অর্থাৎ, $\{x : x \in A \text{ এবং } x \notin B\}$। $A \setminus B$ means elements that are in $A$ but not in $B$.
Therefore, $\{x : x \in A \text{ and } x \notin B\}$.
১১. $F(x) = \frac{2x+2}{x-1}$ হলে রেঞ্জ কত? 11. What is the range of $F(x) = \frac{2x+2}{x-1}$?
Solution:
ধরি, $y = \frac{2x+2}{x-1} \implies xy - y = 2x + 2 \implies xy - 2x = y + 2 \implies x(y - 2) = y + 2 \implies x = \frac{y+2}{y-2}$।
এখানে হর $y-2 \neq 0 \implies y \neq 2$। সুতরাং রেঞ্জ $\mathbb{R} \setminus \{2\}$। Let $y = \frac{2x+2}{x-1} \implies xy - y = 2x + 2 \implies xy - 2x = y + 2 \implies x(y - 2) = y + 2 \implies x = \frac{y+2}{y-2}$.
Denominator $y-2 \neq 0 \implies y \neq 2$. Range is $\mathbb{R} \setminus \{2\}$.
১২. একটি ফাংশন এক-এক (One-one) হবে যদি- 12. A function is one-one if-
Solution:
এক-এক ফাংশনের সংজ্ঞানুসারে, ডোমেনের ভিন্ন ভিন্ন সদস্যের ইমেজ ভিন্ন হবে। গাণিতিকভাবে: $f(x_1) = f(x_2) \implies x_1 = x_2$। By definition of a one-one function, different elements in the domain have different images. Mathematically: $f(x_1) = f(x_2) \implies x_1 = x_2$.
১৩. সার্বিক সেট $U = \{1,2,3,4,5,6\}$ এবং $A = \{1,3,5\}$ হলে $A^c$ বা $A'$ কত? 13. Universal set $U = \{1,2,3,4,5,6\}$ and $A = \{1,3,5\}$. What is $A^c$ or $A'$?
Solution:
$A^c = U \setminus A = \{1,2,3,4,5,6\} \setminus \{1,3,5\} = \{2,4,6\}$। $A^c = U \setminus A = \{1,2,3,4,5,6\} \setminus \{1,3,5\} = \{2,4,6\}$.
১৪. $A = \{a, b\}$ এবং $B = \{c\}$ হলে, $A \times B = ?$ 14. If $A = \{a, b\}$ and $B = \{c\}$, what is $A \times B$?
Solution:
কার্তেসীয় গুণজ: $A \times B = \{(x, y) : x \in A \text{ এবং } y \in B\}$
$= \{(a, c), (b, c)\}$। Cartesian product: $A \times B = \{(x, y) : x \in A \text{ and } y \in B\}$
$= \{(a, c), (b, c)\}$.
১৫. $f(x) = |x|$ ফাংশনটি $\mathbb{R} \to \mathbb{R}$ এ কেমন ফাংশন? 15. What type of function is $f(x) = |x|$ from $\mathbb{R} \to \mathbb{R}$?
Solution:
$f(2) = |2| = 2$ এবং $f(-2) = |-2| = 2$। ভিন্ন ইনপুটের একই আউটপুট। তাই এটি এক-এক নয়।
রেঞ্জ $[0, \infty) \neq \mathbb{R}$ (কো-ডোমেন), তাই অনটুও নয়। $f(2) = |2| = 2$ and $f(-2) = |-2| = 2$. Different inputs yield same output. Thus, it is not one-one.
Range is $[0, \infty) \neq \mathbb{R}$ (co-domain), so it's not onto either.
১৬. $A = \{1, 2\}, B = \{2, 3\}$ এবং $C = \{3, 4\}$ হলে $A \cap (B \cup C) = ?$ 16. If $A = \{1, 2\}, B = \{2, 3\}$ and $C = \{3, 4\}$, what is $A \cap (B \cup C)$?
Solution:
প্রথমে, $B \cup C = \{2, 3, 4\}$।
এরপর, $A \cap (B \cup C) = \{1, 2\} \cap \{2, 3, 4\} = \{2\}$। First, $B \cup C = \{2, 3, 4\}$.
Then, $A \cap (B \cup C) = \{1, 2\} \cap \{2, 3, 4\} = \{2\}$.
১৭. $x \in (2, 5]$ অসমতাটিকে কীভাবে লেখা যায়? 17. How can the inequality $x \in (2, 5]$ be written?
Solution:
প্রথম বন্ধনী '(' মানে $<$ (অন্তর্ভুক্ত নয়) এবং তৃতীয় বন্ধনী ']' মানে $\le$ (অন্তর্ভুক্ত)।
তাই, $(2, 5]$ মানে $2 < x \le 5$। The parenthesis '(' means $<$ (exclusive) and bracket ']' means $\le$ (inclusive).
Therefore, $(2, 5]$ means $2 < x \le 5$.
১৮. $A$ ও $B$ সেটের জন্য, $n(A \setminus B) + n(A \cap B)$ সমান কত? 18. For sets $A$ and $B$, what does $n(A \setminus B) + n(A \cap B)$ equal to?
Solution:
ভেনচিত্র থেকে দেখা যায়, $A$ সেটের দুটি অংশ: যা শুধু $A$ তে আছে ($A \setminus B$) এবং যা উভয়েই আছে ($A \cap B$)।
এই দুটোর যোগফল পুরো $A$ সেট। অর্থাৎ $n(A)$। From a Venn diagram, set $A$ has two parts: elements only in $A$ ($A \setminus B$) and elements in both ($A \cap B$).
Their sum gives the entire set $A$. Thus, $n(A)$.
১৯. $g(x) = x^3 - 3$ হলে, $g^{-1}(5) = ?$ 19. If $g(x) = x^3 - 3$, what is $g^{-1}(5)$?
Solution:
ধরি $g(x) = 5 \implies x^3 - 3 = 5 \implies x^3 = 8 \implies x = 2$। Let $g(x) = 5 \implies x^3 - 3 = 5 \implies x^3 = 8 \implies x = 2$.
২০. $y = 3x$ সরলরেখাটি ফাংশন কি না যাচাই করার জন্য কোন পরীক্ষা ব্যবহার করা হয়? 20. Which test is used to verify whether the line $y = 3x$ is a function?
Solution:
লেখচিত্রটি ফাংশন কি না তা যাচাই করতে 'উল্লম্ব রেখা পরীক্ষা' বা 'Vertical line test' ব্যবহার করা হয়। অনুভূমিক রেখা পরীক্ষা (Horizontal line test) ব্যবহার করা হয় এক-এক (One-one) কি না তা যাচাই করতে। The 'Vertical line test' is used to determine if a graph represents a function. The 'Horizontal line test' is used to check if a function is one-one.
